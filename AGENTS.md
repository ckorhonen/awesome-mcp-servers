# Repository agent guide

## Repository workflow and completion

The Markdown catalogue includes translated READMEs. Follow `CONTRIBUTING.md` for concise descriptions, appropriate categories, and alphabetical ordering. Preserve language/platform and official/community markers; update translations only within requested scope.

No application package or build/test command is defined. Verify proposed public sources, changed URLs, duplicates, Markdown, and whitespace. Reachable pages do not prove server safety or availability. Do not install servers, enable MCP configuration, or connect accounts during editorial checks.

Continue the authorized change through relevant validation and repair of failures it causes; preserve unrelated work. Report checks actually run, commands only inspected, and exact missing prerequisites. Ask only when a material decision, missing authorization, or required input blocks progress; continue independent reversible work. Existing mandatory contribution and validation gates still apply.
